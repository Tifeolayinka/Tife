# End Thread

Read [workflow](references/workflow.md), then execute [closing](references/closing.md) in order.
That reference owns closure intent, saving durable knowledge, routing unfinished work, and archiving.

Read the matching outlines in [documents](references/documents.md) when creating context or tracker
entries. Read [testing](references/testing.md) when reconciling test scenarios or verification status.

**Done when:** durable knowledge and unfinished items have verified destinations, the thread is
archived with its actual outcome, and inbound and relative links work. Report the archive path,
verification limits, and outstanding work destinations. If a required save or routing step fails,
leave the thread active and report the failure.

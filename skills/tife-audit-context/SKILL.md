# Audit Context

Read [workflow](references/workflow.md), then follow **Audit: inspect document coherence** in
[review](references/review.md) for scope, checks, and report-versus-cleanup behavior.

Read [documents](references/documents.md) when checking ownership, IDs, or document structure.
Read [testing](references/testing.md) when checking requirement coverage or verification claims.

**Done when:** findings identify affected locations, consequences, and proposed corrections within
the stated scope. Distinguish firm contradictions from open questions and coverage gaps from test
failures. For authorized cleanup, verify corrections and links and list unresolved issues.
Audit-only requests leave all documents unchanged.
